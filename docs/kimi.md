## 📐 四大核心页面设计详解

### 1. 发帖页（三步流程）

```
Step 1: 选择类型（4选1大卡片）
  ├─ 视觉区分：选中态用彩色边框+背景，未选中用灰色边框
  ├─ 每个卡片包含：图标、标题、描述、适合人群标签
  └─ 底部安全提示区，降低用户顾虑

Step 2: 填写表单（以"找合伙人"为例）
  ├─ 字段分组：基础信息 → 项目信息 → 合作信息 → 联系方式
  ├─ 实时字数统计（标题50字、简介300字、技术需求200字）
  ├─ 合作方式：多选标签（点击切换选中态）
  ├─ 标签选择：多选pill按钮，选中变黑底白字
  ├─ AI润色区：独立卡片，蓝色主题，突出"一键润色"按钮
  │   └─ 润色结果展示：原文对比 + 采用/放弃按钮
  └─ 底部操作：发布（主按钮）+ 预览（次按钮）

Step 3: 发布成功 → 跳转到帖子详情
```

**设计要点**：
- **不写简历，只填空**：每个字段都有placeholder示例，降低思考成本
- **AI润色前置**：在提交前就给用户价值，不是事后优化
- **联系方式保护**：默认勾选"需申请查看"，保护用户隐私

### 2. 帖子详情页（双栏布局）

```
┌────────────────────────┬─────────────────────┐
│  左侧：帖子内容（2/3）   │  右侧：侧边栏（1/3） │
├────────────────────────┼─────────────────────┤
│  标签组（多色pill）      │  发布者信息卡片      │
│  标题（H1）              │  ├─ 头像+昵称+身份   │
│  发布者信息卡片          │  ├─ 实名状态         │
│  ├─ 头像+昵称+身份标签   │  ├─ 发布统计         │
│  ├─ 浏览/讨论数据        │  └─ 查看主页按钮     │
│  帖子内容（按模板展示）   │                      │
│  ├─ 每个字段：标签+内容   │  相似帖子推荐        │
│  └─ 技术需求用列表展示   │  ├─ 3条相关帖子      │
│  联系方式申请区（琥珀色） │  └─ 标题+城市+浏览量 │
│  讨论区                  │                      │
│  ├─ 评论输入框           │  安全提示卡片        │
│  ├─ 评论列表（嵌套回复）  │  ├─ 4条安全建议      │
│  └─ 加载更多             │  └─ 蓝色主题         │
└────────────────────────┴─────────────────────┘
```

**设计要点**：
- **发布者信息前置**：建立信任，让用户知道谁在发帖
- **字段标签化**：每个信息项用灰色小标签标注，像阅读结构化数据
- **讨论区即信任**：公开讨论比私信更透明，减少骗子
- **相似帖子推荐**：增加页面停留时间和交叉浏览

### 3. 个人中心（四栏布局）

```
┌──────────┬──────────────────────────────────────┐
│ 左侧信息  │           右侧内容区                  │
│ （1/4）  │            （3/4）                    │
├──────────┼──────────────────────────────────────┤
│ 头像+昵称 │  Tab导航：[我的帖子][联系方式申请][设置] │
│ 身份标签  │                                      │
│ 实名状态  │  Tab: 我的帖子                        │
│ 基础信息  │  ├─ 帖子列表（可编辑/刷新/删除）       │
│ 统计数字  │  ├─ 每条显示：标签+标题+数据+操作按钮   │
│          │  └─ 底部：发布新帖子按钮               │
│          │                                      │
│ 编辑资料  │  Tab: 联系方式申请                    │
│ 按钮      │  ├─ 申请列表（头像+昵称+状态+消息）      │
│          │  ├─ 待处理：同意/拒绝按钮              │
│          │  ├─ 已同意：展示联系方式               │
│          │  └─ 已拒绝：灰色显示                   │
│          │                                      │
│          │  Tab: 账号设置                        │
│          │  └─ 表单：昵称/城市/身份/技术栈/简介    │
└──────────┴──────────────────────────────────────┘
```

**设计要点**：
- **Sticky侧边栏**：左侧信息卡片随页面滚动固定，始终可见
- **帖子管理三操作**：编辑（修改内容）、刷新（更新时间=置顶）、删除
- **联系方式申请可视化**：用状态标签（待处理/已同意/已拒绝）+ 操作按钮，一目了然
- **隐藏帖子保留**：已隐藏的帖子灰色显示，可恢复，避免误删

### 4. 联系方式申请弹窗

```
┌─────────────────────────────┐
│  申请查看联系方式              │
│  向发布者发送申请...           │
├─────────────────────────────┤
│  [自我介绍输入框]              │
│  提示：简单介绍你的背景...      │
├─────────────────────────────┤
│  [发送申请]  [取消]           │
└─────────────────────────────┘
```

**设计意图**：强制用户写一句话自我介绍，过滤掉"批量海投"的骚扰者，提高申请质量。

## 🎨 设计系统速查

| 元素 | 规则 |
|------|------|
| **颜色语义** | 🔴红色=紧急/重要，🟢绿色=人才/已实名，🔵蓝色=合伙人/AI，🟡琥珀=项目/外包，🟣紫色=融资 |
| **卡片边框** | 默认`gray-200`，hover`gray-400`，无阴影（Craigslist风格） |
| **按钮层级** | 主操作=黑底白字，次操作=白底灰边，危险操作=白底红边 |
| **字体** | 标题24px/700，正文14px/400，辅助12px/400 |
| **间距** | 紧凑为主，信息密度高，一屏展示尽可能多的内容 |
