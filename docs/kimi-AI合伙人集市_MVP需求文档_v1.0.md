# AI合伙人集市 — MVP需求文档 (PRD)

> **版本**: v1.0  
> **日期**: 2026-07-21  
> **目标**: 1人+AI，2-3周完成MVP开发并上线  
> **技术栈**: Next.js 15 + Supabase + Tailwind CSS + shadcn/ui + Kimi K3 API

---

## 一、产品定位

### 1.1 一句话描述
中国第一个面向35+资深技术人的AI创业合伙信息平台，采用Craigslist极简模式，让有经验的工程师与AI创业项目/资本高效对接。

### 1.2 核心价值主张
- **对技术人**: 不写简历，用自然语言展示能力，找到值得投入的AI创业机会
- **对项目方/企业**: 低门槛发布需求，精准触达有经验的技术合伙人
- **对平台**: 纯信息撮合，不介入交易，建立信任社区

### 1.3 目标用户画像

| 角色 | 典型用户 | 核心痛点 | 使用场景 |
|------|---------|---------|---------|
| **技术合伙人候选人** | 前阿里P8，15年Java，离职找AI创业 | 招聘网站没有"创业合伙"场景，简历投递石沉大海 | 发布"我是人才"帖，等待项目方联系 |
| **AI创业项目创始人** | 有想法+MVP，缺CTO | 找不到愿意拿股权的资深工程师 | 发布"找合伙人"帖，筛选候选人 |
| **企业技术负责人** | 需要AI项目外包/顾问 | 传统外包平台质量参差不齐 | 发布"接项目"帖，找有经验的技术顾问 |
| **投资人/FA** | 寻找优质AI项目 | 项目来源分散，筛选成本高 | 浏览"找资金"帖，发现早期项目 |

## 二、MVP功能范围

### 2.1 功能优先级矩阵

```
P0 (必须): 用户注册/登录、发布帖子、浏览帖子、帖子详情、城市筛选、分类筛选
P1 (重要): 联系方式申请/解锁、帖子讨论区、实名认证、AI辅助发帖
P2 (增值): 帖子置顶、搜索、用户个人主页、管理后台
P3 (后续): 站内私信、AI智能匹配、企业认证、支付系统
```

### 2.2 功能清单

#### P0 — 核心功能

| 功能模块 | 功能点 | 用户故事 | 验收标准 |
|---------|--------|---------|---------|
| **用户系统** | 微信扫码登录 | 作为用户，我想用微信快速登录，无需注册密码 | 1. 点击微信登录按钮 → 弹出微信授权二维码 2. 扫码后自动创建账户并登录 3. 首次登录引导填写基础信息 |
| | 基础信息填写 | 作为首次登录用户，我想快速填写我的身份标签 | 1. 选择身份："我是技术人" / "我有项目" / "我是投资人" 2. 填写昵称、所在城市 3. 可选：技术栈/项目简介 |
| **帖子系统** | 发布"找合伙人"帖 | 作为项目创始人，我想发布招募技术合伙人的信息 | 1. 选择帖子类型：找合伙人 2. 填写模板字段（见3.2节） 3. AI辅助润色按钮 4. 预览并发布 5. 发布后跳转到帖子详情 |
| | 发布"我是人才"帖 | 作为技术人，我想展示我的能力和合作意愿 | 1. 选择帖子类型：我是人才 2. 填写模板字段（见3.2节） 3. AI辅助润色按钮 4. 预览并发布 |
| | 发布"接项目"帖 | 作为企业方，我想发布外包/顾问需求 | 1. 选择帖子类型：接项目 2. 填写模板字段 3. 预览并发布 |
| | 发布"找资金"帖 | 作为创业者，我想发布融资需求 | 1. 选择帖子类型：找资金 2. 填写模板字段 3. 预览并发布 |
| | 浏览帖子列表 | 作为访客，我想按城市和分类浏览最新帖子 | 1. 默认展示全部城市、全部类型 2. 点击城市标签筛选 3. 点击分类卡片筛选 4. 按发布时间倒序排列 5. 每条帖子显示：标题、摘要、标签、浏览量、讨论数、发布时间 |
| | 帖子详情页 | 作为访客，我想查看帖子完整内容 | 1. 展示帖子完整内容 2. 展示发布者基础信息（昵称、城市、身份标签） 3. 展示讨论区 4. 联系方式区域（需申请查看） |
| **筛选系统** | 城市筛选 | 作为用户，我想只看某个城市的帖子 | 1. 顶部城市标签栏：全部、北京、上海、深圳、杭州、成都、远程 2. 点击切换，帖子列表实时刷新 |
| | 分类筛选 | 作为用户，我想只看某个类型的帖子 | 1. 三个分类卡片：找合伙人、接项目、找资金 2. 点击卡片筛选 3. 可与城市筛选叠加 |
| | 标签筛选 | 作为用户，我想按技术方向筛选 | 1. 标签栏：AI大模型、SaaS、出海、Agent、全栈、架构师、35+优先、股权合伙 2. 点击多选，帖子列表实时刷新 |

#### P1 — 重要功能

| 功能模块 | 功能点 | 用户故事 | 验收标准 |
|---------|--------|---------|---------|
| **联系方式系统** | 申请查看联系方式 | 作为访客，我想获取帖子发布者的联系方式 | 1. 点击"申请查看联系方式"按钮 2. 弹出申请理由输入框（可选） 3. 提交后，发布者收到通知 4. 发布者同意后，申请者看到联系方式 |
| | 联系方式管理 | 作为发布者，我想控制谁可以看到我的联系方式 | 1. 在帖子管理页面查看所有申请 2. 可选择"同意"或"拒绝" 3. 同意后，对方在帖子详情页看到联系方式 |
| **讨论区** | 发表评论 | 作为访客，我想在帖子下方提问或讨论 | 1. 在帖子详情页底部发表评论 2. 评论支持纯文本，限制500字 3. 评论按时间倒序排列 4. 发布者可以回复评论 |
| **实名认证** | 微信实名认证 | 作为用户，我想通过实名认证增加可信度 | 1. 在个人中心点击"实名认证" 2. 调用微信实名认证API 3. 认证通过后，帖子显示"✓ 已实名"标签 |
| **AI辅助** | AI润色帖子 | 作为发布者，我想让AI帮我优化帖子表达 | 1. 在发帖页面点击"AI润色"按钮 2. 调用Kimi K3 API 3. 展示润色后的内容，用户可选择"采用"或"放弃" 4. 润色方向：更专业、更简洁、更吸引人 |

#### P2 — 增值功能

| 功能模块 | 功能点 | 用户故事 | 验收标准 |
|---------|--------|---------|---------|
| **帖子管理** | 编辑/删除帖子 | 作为发布者，我想管理我发布的帖子 | 1. 在个人中心"我的帖子"列表 2. 可编辑帖子内容 3. 可删除帖子（确认弹窗） 4. 可刷新帖子时间（置顶效果） |
| **搜索** | 关键词搜索 | 作为用户，我想搜索特定内容 | 1. 顶部搜索框 2. 支持按标题、内容、标签搜索 3. 实时展示搜索结果 |
| **个人主页** | 用户主页 | 作为访客，我想查看某个用户的所有帖子 | 1. 点击用户名跳转到个人主页 2. 展示用户基础信息 3. 展示该用户发布的所有帖子 |
| **管理后台** | 内容审核 | 作为管理员，我想审核用户发布的内容 | 1. 后台展示待审核帖子列表 2. 可"通过"或"拒绝" 3. 拒绝时填写拒绝原因 4. 自动审核：调用Kimi K3进行初筛 |
| | 用户管理 | 作为管理员，我想管理平台用户 | 1. 用户列表，支持搜索 2. 可封禁/解封用户 3. 查看用户发布记录 |
| | 数据统计 | 作为管理员，我想看平台运营数据 | 1. 今日新增帖子数 2. 今日新增用户数 3. 总帖子数 4. 总用户数 5. 按城市/分类的帖子分布 |

### 4.2 数据库Schema (PostgreSQL)

```sql
-- 用户表
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    auth_id TEXT UNIQUE NOT NULL, -- Supabase Auth user ID
    nickname TEXT NOT NULL,
    avatar_url TEXT,
    city TEXT,
    identity_type TEXT CHECK (identity_type IN ('tech', 'founder', 'investor', 'other')),
    tech_stack TEXT[], -- 技术栈数组
    bio TEXT,
    is_verified BOOLEAN DEFAULT FALSE,
    verified_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 帖子表
CREATE TABLE posts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    post_type TEXT CHECK (post_type IN ('find_partner', 'i_am_talent', 'find_project', 'find_funding')),
    title TEXT NOT NULL,
    city TEXT NOT NULL,
    is_remote BOOLEAN DEFAULT FALSE,

    -- 找合伙人字段
    project_stage TEXT,
    project_desc TEXT,
    tech_requirement TEXT,
    cooperation_type TEXT[],
    equity_salary TEXT,
    team_info TEXT,

    -- 我是人才字段
    current_status TEXT,
    available_time TEXT,
    expected_cooperation TEXT[],
    portfolio TEXT,

    -- 接项目字段
    project_type TEXT,
    budget TEXT,
    duration TEXT,
    work_mode TEXT,

    -- 找资金字段
    funding_amount TEXT,
    equity_offer TEXT,
    team_background TEXT,

    -- 通用字段
    contact_info TEXT,
    contact_visible BOOLEAN DEFAULT FALSE,
    tags TEXT[],
    status TEXT DEFAULT 'active' CHECK (status IN ('active', 'hidden', 'deleted')),
    view_count INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 联系方式申请表
CREATE TABLE contact_requests (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    post_id UUID REFERENCES posts(id) ON DELETE CASCADE,
    requester_id UUID REFERENCES users(id) ON DELETE CASCADE,
    message TEXT,
    status TEXT DEFAULT 'pending' CHECK (status IN ('pending', 'approved', 'rejected')),
    created_at TIMESTAMP DEFAULT NOW(),
    responded_at TIMESTAMP
);

-- 评论表
CREATE TABLE comments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    post_id UUID REFERENCES posts(id) ON DELETE CASCADE,
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    content TEXT NOT NULL,
    parent_id UUID REFERENCES comments(id) ON DELETE CASCADE, -- 回复评论
    created_at TIMESTAMP DEFAULT NOW()
);

-- 标签表
CREATE TABLE tags (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name TEXT UNIQUE NOT NULL,
    category TEXT,
    usage_count INTEGER DEFAULT 0
);

-- 创建索引
CREATE INDEX idx_posts_city ON posts(city);
CREATE INDEX idx_posts_type ON posts(post_type);
CREATE INDEX idx_posts_status ON posts(status);
CREATE INDEX idx_posts_created_at ON posts(created_at DESC);
CREATE INDEX idx_posts_tags ON posts USING GIN(tags);
CREATE INDEX idx_contact_requests_post ON contact_requests(post_id);
CREATE INDEX idx_comments_post ON comments(post_id);
```

const polishPost = async (content, postType) => {

${content}

  const response = await fetch('https://api.moonshot.cn/v1/chat/completions', {
