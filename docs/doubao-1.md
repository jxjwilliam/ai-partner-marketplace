# 核心调研结论先讲清楚

目前分为两类需求：
- 寻找技术合伙人 / AI 创业组队
- 大龄资深工程师（35+、架构师、技术专家）求职、副业、项目合作

**中国不存在和 craigslist.org 形态、定位完全对等的网站，更没有专门「垂直面向大龄专业人士（资深软件工程师）+招聘+合伙创业」一体式分类信息站点。**
先简单对比两者底层差异，方便你理解为什么国内复刻不出来：
## Craigslist 核心特质
1. **极简通用分类广告社区**：同城、个人直连、低门槛免费发帖；板块包含全职招聘、兼职、项目合作、寻找创业伙伴、技能服务、各类供需；
2. **无重度中介、算法推荐弱、不强制简历体系**；
3. 大量中年资深专业人士自发发帖：求职、接项目、寻找联合创始人、技术合伙；
4. 不分应届生/大龄，所有人在同一个信息广场自由对接。

## 国内互联网环境天然缺少同类平台的原因
1. 监管规则：开放式无门槛综合分类信息平台合规成本极高，早年大量类似站点陆续关停；
2. 商业路径：国内平台普遍走向「招聘中介化、会员付费、流量竞价置顶」，免费个人直贴生态萎缩；
3. 用户分层：国内市场把「求职招聘」「创业找合伙人」「外包接单」强行拆成不同赛道平台，没有一个统一广场。

下面分两类给你清单：
## 一、最接近Craigslist「自由发帖、个人直连」气质的平台（按匹配度排序）
### 1. V2EX（https://www.v2ex.com）【最推荐，IT技术人群高度重合】
✅ 匹配点：
论坛式分类信息，**「酷工作」板块**，大量35+资深后端、架构师、AI工程师；可以发：全职求职、远程岗位、项目外包、寻找技术合伙人、组队创业；个人直接沟通，无中介抽成。
人群：程序员、技术负责人、独立开发者、互联网老兵，很多大龄资深软件工程师。
❌ 限制：社区有发帖规则，禁止赤裸裸广告；偏线上技术人群，本地化属性弱（缺少Craigslist同城属性）。

### 2. 电鸭社区（https://tedduck.com）
定位：远程工作、自由职业、项目合作社区
✅ 大量资深工程师，很多厌倦大厂内卷、寻求兼职/合伙/远程全职；支持发布「寻找合伙人、AI创业项目组队」；氛围偏成熟开发者，30+、35+占比很高。
❌ 同城属性弱，以远程合作为主。

### 3. 缘创派 https://www.yuanchuangpai.com
国内最早主打**寻找创业合伙人**垂直平台
✅ 可以发布项目招募技术合伙人，大量从业10年以上技术老兵；支持筛选AI、软件研发方向；类似Craigslist里「创业组队」板块。
❌ 只聚焦合伙，普通求职岗位很少；近年活跃度下滑；同城匹配功能薄弱。

### 4. 小概率 mirauni.com
独立开发者、初创组队平台，轻量化发帖，不少人寻求AI项目兼职合伙、股权合作；界面简洁，广告少。

### 5. 58同城 / 赶集（国内最接近通用分类信息网站）
⚠️ **强烈不推荐用来找大龄资深软件工程师合伙人**
虽然形态是国内版Craigslist，但用户主体是蓝领、基层服务业；IT高薪资深人才极少；中介泛滥，技术合伙信息质量极低，浪费时间。

> 总结：**如果目标是软件工程师、AI赛道专业人士，不要把58作为主要渠道。**

## 二、专门面向「大龄资深专业人士、中高端技术人才」渠道（求职+顾问+项目合作）
### 1. 再鸣 revoice.cn
国内极少数**明确主打40+高端人才**平台
定位：40岁以上职场精英，提供全职、兼职、项目顾问、创业合作机会；人群包含资深技术专家、技术负责人。
✅ 精准匹配你「大龄专业人士」需求；
❌ 用户体量不大，AI、软件技术赛道供给有限。

### 2. 脉脉（实名职场社交）
最实用的综合渠道，可以当成「中文职场版轻量化Craigslist」
- 自由发布动态：求职、寻找技术合伙人、项目合作；
- 搜索关键词：资深架构师、大模型、独立开发、寻找创业机会；
大量35+大厂资深工程师，很多人表达想转型创业、寻找项目。
缺点：广告众多，需要主动筛选。

### 3. 猎聘
中高端招聘平台，聚集大量资深技术专家，适合雇佣；**但几乎没有「寻找合伙人、股权创业」场景**，偏向薪资雇佣。

# 五、关键风险提醒
1. 不要指望单一网站一网打尽；国内市场「招聘」和「创业合伙」天然分割；
2. 大龄资深工程师普遍反感过度画饼，发布招募文案务必写清合作模式：薪资/股权/分成、项目阶段、退出机制；
3. 所有线上平台仅作为线索渠道，重要合伙合作务必线下深度沟通，签订书面协议；
4. 不存在任何平台可以按「年龄」筛选求职者，只能通过从业年限、技术头衔、项目经验间接筛选大龄专业人士。
